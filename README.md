# 🌐 Portfolio – Marcela Freitas

Bem-vindo ao repositório do meu portfólio!

Este projeto foi criado para apresentar quem sou, as minhas habilidades técnicas, os projetos que desenvolvi e a minha trajetória como desenvolvedora Fullstack com foco em UI/UX. O objetivo principal é demonstrar de forma clara e visual o meu trabalho e facilitar o contato com recrutadores, empresas e potenciais clientes.

Este portfólio foi desenvolvido com as seguintes tecnologias:

* **HTML5**
* **CSS3**
* **JavaScript**
* **Figma** (para prototipação e design)
